Any media path and file ownership
There is no /media allowlist. Mount each host folder read/write and set PUID/PGID to the host user that should own generated subtitles. GID or GUID can be used as a PGID alias.
services:
  javbeaconsubs:
    environment:
      PUID: "1000"
      PGID: "1000"
    volumes:
      - "/mnt/data/movies:/mnt/data/movies"
Japanese speech recognition
Qwen3-ASR-1.7B is the Japanese-forced primary recognizer. Balanced retries suspicious lexical output without context, then uses one batched Whisper Large-v3 verification phase before Qwen3-ForcedAligner supplies timing. ReazonSpeech remains experimental and inactive in normal Qwen jobs. Models are cached on the persistent models mount and released between GPU phases.
JAVBEACONSUBS_ASR_BACKEND=qwen
JAVBEACONSUBS_ASR_MODE=balanced
JAVBEACONSUBS_ASR_PROFILE=jav
JAVBEACONSUBS_QWEN_MODEL=Qwen/Qwen3-ASR-1.7B
JAVBEACONSUBS_ALIGNER_MODEL=Qwen/Qwen3-ForcedAligner-0.6B
JAVBEACONSUBS_WHISPER_DEVICE=auto
JAVBEACONSUBS_WHISPER_CPU_TIMEOUT_SECONDS=7200
Fast uses Qwen plus alignment. Balanced adds targeted Qwen retry and Whisper verification for difficult lexical speech. High Accuracy verifies suspicious lexical speech more aggressively. Vocalizations and timing-only problems never invoke fallback ASR. Auto tries CUDA first and retries the complete Whisper batch once on CPU only for CUDA allocation or initialization failures.
Bash post-processing example
#!/usr/bin/env bash
set -euo pipefail
job_json="$(cat)"
printf 'Completed %s (%s files)\n' "$JAVBEACONSUBS_JOB_ID" "$JAVBEACONSUBS_FILES"
curl --fail-with-body --silent --show-error \
  --header 'Content-Type: application/json' \
  --data-binary "$job_json" \
  http://host.docker.internal:8080/subtitles/complete
Profiles, vocabulary, and models
A content profile describes the domain, not the model. Fast uses Qwen plus alignment, Balanced adds targeted Qwen retry and selective Whisper verification, and High Accuracy verifies difficult lexical speech more broadly. Path mappings resolve these two fields independently for every file in mixed recursive folders.
Japanese Recognition Vocabulary is Japanese-only recognition assistance: it is not translation, not blind replacement, and is never dumped wholesale into Qwen. It only helps score otherwise plausible candidates. Translation Glossary v2 separately activates Global plus JAV or GIGA mappings for the contextual translator.
The Models tab shows exact active repositories/revisions and performs manual update checks. Current cached models continue working while providers are offline.
