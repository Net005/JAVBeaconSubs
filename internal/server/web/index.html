Post-processing

Completed job JSON is passed on standard input. Status appears on the job card.

Also receives JAVBEACONSUBS_JOB_ID, JAVBEACONSUBS_EXTERNAL_ID, JAVBEACONSUBS_STATUS and JAVBEACONSUBS_FILES.

REST API

Scan a folder and all subfolders

Any container-visible path is accepted. This example preserves existing subtitles and authenticates using the external API token.

Any media path
There is no /media allowlist. Mount each host folder read/write so subtitles can be written beside the video.
services:
  javbeaconsubs:
    volumes:
      - "/mnt/data/movies:/mnt/data/movies"
Bash post-processing example
#!/usr/bin/env bash
set -euo pipefail
job_json="$(cat)"
printf 'Completed %s (%s files)\n' "$JAVBEACONSUBS_JOB_ID" "$JAVBEACONSUBS_FILES"
curl --fail-with-body --silent --show-error \
  --header 'Content-Type: application/json' \
  --data-binary "$job_json" \
  http://host.docker.internal:8080/subtitles/complete
